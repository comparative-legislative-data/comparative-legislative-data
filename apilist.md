Scottish Parliament Public APIs:
Our Application Programming Interfaces (APIs) will provide you with a set of functions that you call to get a contracted return.

For example, for a given Id will return you the appropriate record from our database that you can use directly in your applications. This means when we update our database your application will be updated dynamically. APIs will currently only be available in JSON.
